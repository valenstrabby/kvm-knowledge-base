 # Learning GitHub Pages and Documentation

 ## Introduction

 This project is about learning how tocreate docs and publish it using GitHub pages.
 
 The documentation is written using Markdown files. Markdown allows us to create headings, list, and other types of formatted content. 

 ## What is GitHub Pages?

 GitHub Pages is a service that allows us to create and publisha website from GitHuv repository.

 It can be used for project websites, documentation,portfolios, and other websites.
